# KWE Wallpapers

A combined collection of desktop wallpapers, gathered from two community wallpaper libraries and merged into a single, sequentially numbered set.

## Sources

This pack combines wallpapers from:

| Collection | Source |
| --- | --- |
| The LGL Wallpaper Collection | [github.com/linuxgamerlife/wallpapers](https://github.com/linuxgamerlife/wallpapers) |
| BlackDon's Wallpaper Collection | [gitlab.com/theblackdon/wallpapers](https://gitlab.com/theblackdon/wallpapers) |

Wallpapers from both collections are merged in one place and renumbered from `0001` to `0737` so there are no filename collisions.

## What's inside

- **737 wallpapers** (~2.3 GB)
- **Formats:** JPEG (`.jpg` / `.jpeg`), PNG (`.png`), WebP (`.webp`)
- **Resolutions:** mixed, mostly 3440×1440 (21:9 ultrawide), with others ranging from 1920×1080 up to 8K

## Usage

Clone the repository and point your desktop's wallpaper / background settings at the cloned folder:

```bash
git clone https://github.com/WeeCragLinux/KWE-Wallpapers.git
```
